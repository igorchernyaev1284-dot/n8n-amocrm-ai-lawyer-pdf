# ИИ-Юрист для amoCRM: Авто-генерация исковых заявлений (n8n)

Готовый шаблон (Workflow) для n8n, который решает главную проблему юридических отделов — опечатки в документах, неправильное склонение ФИО и долгую ручную верстку исков.

## 🔴 Проблема стандартных решений
Младшие юристы и менеджеры часто копипастят старые иски. Они забывают менять ИНН, ошибаются в падежах (например, пишут "в лице Генерального директора Иванов Иван") или неправильно прописывают сумму прописью. Из-за этого суды оставляют иски без движения. Стандартные виджеты-генераторы в CRM часто ломаются на сложной русской грамматике.

## 🟢 Как работает эта архитектура
Этот воркфлоу перехватывает смену статуса сделки в amoCRM и делает всю работу за юриста:
1. Забирает сухие данные из карточки (ИНН, Сумма, ФИО, Название).
2. **Guardrails:** Проверяет, все ли обязательные поля заполнены. Если нет — шлет алерт в Telegram.
3. **Математика:** Автоматически переводит сумму долга из цифр в текст по правилам русского языка (чистым JS-кодом).
4. **LLM (ИИ):** Точечно использует GPT-4o-mini строго для одной задачи — правильного склонения ФИО директора в Родительный падеж. Никаких галлюцинаций.
5. **Верстка:** Собирает эталонный HTML-документ по стандартам АПК РФ и ГОСТ.
6. **Конвертация:** Превращает HTML в строгий PDF-файл и отправляет его юристу в Telegram и обратно в карточку amoCRM.

## 🛠 Что под капотом (Техническая реализация)
Вся интеграция построена на чистых `HTTP Request` (REST API v4) для максимальной скорости и стабильности.

**Логика работы узлов:**
*   `Webhook` + `Code` — Отлов триггера из amoCRM и парсинг `lead_id`.
*   `HTTP Request (amoCRM)` — Получение массива данных по сделке.
*   `Code (Парсинг + Валидация)` — Кастомный JS-скрипт. Проверяет наличие ИНН/ФИО и конвертирует числа в текст (алгоритм `numToWordsRu`).
*   `IF` — Маршрутизатор. Если есть пустые поля -> алерт в Telegram. Если всё ок -> идем дальше.
*   `HTTP Request (OpenRouter/LLM)` — API-запрос к нейросети с жестким промптом на возврат JSON (`fio_genitive`).
*   `Code (HTML)` — Сборка итогового документа через шаблонные строки.
*   `HTTP Request (PDFShift)` — Рендеринг HTML в PDF.
*   `Telegram` + `amoCRM (Notes)` — Дистрибуция готового файла.

## 🚀 Как установить
1. Скачайте файл `ai-lawyer-amocrm.json` из этого репозитория.
2. В вашем инстансе n8n нажмите `Import from File`.
3. Подключите свои Credentials для amoCRM (OAuth2/Long-lived token), Telegram API, OpenRouter (для LLM) и PDFShift (или любого другого конвертера).
4. Настройте Webhook в amoCRM на нужный статус воронки.
5. Активируйте Workflow.
